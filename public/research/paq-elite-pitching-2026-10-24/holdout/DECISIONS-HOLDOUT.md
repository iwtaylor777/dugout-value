# Implementation decisions for the holdout test (dated; none changes the locked protocol's substance)

- 2026-10-24, before any download. Postseason fetch windows open September 25 of each year instead of "the day after the regular season ends". The postseason game-type filter (`hfGT=F|D|L|W|`) excludes regular-season rows, so this only guarantees full coverage. Using the regular-season fetch window's end date + 1 would have missed 2024's Wild Card games on October 1. The 2026 cutoff stays at games with `game_date ≤ 2026-10-23`.

- 2026-10-24, after the audit and table build, before any model fit or elite x outcome tabulation (implementation of PROTOCOL-HOLDOUT.md; code in `code/holdout.py`):
  1. **Loader.** PAQ's `load.load_season` keeps only `game_type == "R"`. `code/hload.py` is that function copied mechanically with one change: a `game_types` argument in the filter line, plus recording game-type counts. Postseason blocks use F/D/L/W; 2020 uses R. Everything downstream is PAQ's own code, unmodified: `score.build`/`attach_pa` (pa_x, tto, by_starter, pinch_hit, in_denominator, woba_denom), `load.audit_counts`/`audit_finalize`, `run.unscorable_report`. Postseason `pa_id` = PAQ season base + 500,000, so ids never collide with regular-season ids.
  2. **2026 cutoff.** Applied after loading, on the game's re-dated `game_date` (≤ 2026-10-23). 0 rows were dropped, because the fetch window already ended on 10-23.
  3. **Frozen postseason inputs.** PAQ's `score.pregame_hitter_table` and `score.pitcher_pregame_table` are queried on the day after the last regular-season game, through dummy query rows. The dummy rows have woba_denom 0, n_pitches 0, no K/BB and pa_x NaN, so they add nothing to any P1, xwOBA or league sum, and both tables use only games strictly before the query date. A unit test on a truncated 2022 regular season (`code/test_holdout.py`) checks P1s, xwOBA_s, xwOBA_allowed_s and lg_x against direct full-season sums.
     - 2024: the regular season ended with the Sep 30 NYM–ATL makeup doubleheader, and the Wild Card began Oct 1. The freeze date equals the first postseason date, and the inputs still use regular-season games only.
  4. **Hitters with no regular-season history.** A postseason hitter with no scored regular-season pitches or PAs gets PAQ's shrinkage value with n = 0: P1 = 0 and xwOBA = league. This is the same as PAQ's pre-game value for a hitter's first regular-season game. Such PAs are kept, not counted as missing. There was 1 such hitter (2025).
  5. **Centring and scaling.** z(P1) is centred at the PA-weighted mean of the analysis sample within each block-season (2021-RS, 2021-post, …, 2026-post) and divided by 0.154. z(xwOBA) uses the same cells' sample mean and SD (ddof 1).
  6. **Design details.**
     - Season dummies are 2022–2026 (base 2021) with a postseason indicator. 2021-post is identified by the postseason indicator; the 2022–26 postseason cells by their season dummies.
     - Park = `home_team` as recorded, with dummies for all but the first level.
     - In sub-sample fits, columns that are constant or duplicate an earlier column are dropped and listed in results.json: `starter` in S1; `postseason` and `postseason × elite` in single-block fits; season dummies when only one season is present.
     - Standard errors are PAQ's `tests.ols_cluster`, two-way by hitter and pitcher, including its small-sample factor.
  7. **Holm (S1).** The H1 verdict follows H1's own pass rule (one-sided p < 0.025 and both block signs positive). Holm with m = 2 at one-sided 0.025 is applied to {H1, S1}. S1 is reported as supporting H1 only if H1 passes and S1 clears its Holm threshold. If H1 passes its rule but does not clear its own Holm threshold, that is reported alongside.
  8. **Power and size.** Reported power uses each fit's realised SE at one-sided α = 0.025 for β = 0.004 and 0.0053. Per-postseason-season fits are descriptive only.
  9. **Observed, not a deviation.** The 2020 rule (≥ 300 scored 2020 pitches) leaves 366 pitchers, so the 2021 regular-season block has 106,559 PAs (62% of non-pinch-hit wOBA-denominator PAs) rather than the about 133,000 a full prior season gives. Its SE will be larger than the 0.0022 planned. The postseason block has 16,900 PAs. Audit: postseason game counts 37/40/41/43/47/36 (2026 through 10-23) match the public record for 2021–25, and all PAQ audit checks pass in every block (`out/audit_holdout.json`).
